# My dotfiles

---
Using arch with hyprland

## Requirements

Ensure to have this installed on your system

- Git
- Stow
- dunst
- nvim
- ttf-jetbrains-mono-nerd
- kitty
- waybar
- ohmyposh
- fuzzel
- dolphin

## Installation

First clone this repository

```zsh
git clone git@github.com/abdiel-sys/hyprland-dotfiles.git $HOME/.dotfiles
cd .dotfiles
```

Then use GNU stow to create the symlinks

```zsh
stow .

```
